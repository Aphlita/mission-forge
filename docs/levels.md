# 贡献者等级

等级用于描述参与者已经展示的工程能力，作为任务选择与培养目标的依据。

| 等级 | 名称 | 能力与成果依据 |
| --- | --- | --- |
| L0 | 学习者（Learner） | 能够准备开发环境、运行基础示例并解释运行结果 |
| L1 | 见习贡献者（Apprentice） | 能够在导师指导下复现问题、完成明确范围的任务并提供验证记录 |
| L2 | 贡献者（Contributor） | 能够独立完成任务、提交符合上游要求的成果并处理评审意见 |
| L3 | 高级贡献者（Advanced Contributor） | 能够分析复杂问题、设计修改方案、评审贡献并指导其他参与者 |
| L4 | 维护者培养（Maintainer Track） | 能够持续承担模块维护、版本验证与社区协作职责 |

阶段评估按照[贡献评估标准](assessment.md)审查实际成果。导师记录建议等级、证据和下一阶段目标，由组织者复核后向参与者反馈。参与者可以补充证据并申请复核。

L4 表示 Mission Forge Contributor Program（MFCP）内部培养阶段。上游项目的维护权限由对应社区决定。具体激励安排见[津贴与奖励](stipends.md)。
