## References and prompts

Zephyr uses the [nRF52840 DK photograph from the Zephyr repository](https://github.com/zephyrproject-rtos/zephyr/blob/main/boards/nordic/nrf52840dk/doc/img/nrf52840dk_nrf52840.jpg).
Yocto Project uses the [official project overview](https://www.yoctoproject.org/about/project-overview/)
and its [blue mountain panorama](https://yocto.dev-lfprojects3.linuxfoundation.org/wp-content/uploads/sites/32/2023/10/hero-blue.jpg).
Both illustrations also use the project's soft 3D artwork as a style reference.

### Zephyr

> Create an editorial project card using image 1 as the real hardware reference
> from Zephyr community documentation (nRF52840 DK) and image 2 as the style
> reference. Title exactly "Zephyr", large bold dark-purple sans-serif at upper
> left, with 7% safe margins. Illustrate the actual reference board shape: wide
> blue rectangular PCB, long black pin headers, central ICs, four buttons toward
> the lower right, USB connectors. Preserve recognizable board proportions,
> simplify fine silkscreen rather than invent labels. Soft studio 3D
> illustration, pale ivory background and subtle purple accent ribbons; board
> in lower right with space around title. 3:2 landscape. No other text, no extra
> logos or watermarks.

### Linux

### Yocto Project

> Create an editorial project card using image 1, the Yocto Project official
> website blue mountain panorama, as the visual reference and image 2 only for
> the soft 3D illustration quality. Title exactly "Yocto Project", large bold
> dark-navy sans-serif at upper left with 7% margins, clearly legible at 400px
> width. Feature layered blue mountain silhouettes fading into a pale
> ivory-blue sky, echoing the reference. In the lower right foreground place a
> modest embedded computer with a few translucent blue modular software tiles,
> harmoniously integrated and smaller than the landscape. Restrained blue and
> teal palette. Polished soft illustrated rendering, 3:2 landscape, generous
> breathing room. No other text, no official logo, no watermark.
